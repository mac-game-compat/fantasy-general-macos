# Compatibility record

Status: untested. Repository setup alone establishes no game compatibility.

For each real test, record:

- Test date, macOS version, and Mac CPU architecture (Intel or Apple silicon).
- Game edition/source and version, without serial numbers or account details.
- Emulator name/version, architecture, and any translation layer used.
- Configuration changes relative to the example and exact reproduction steps.
- Launch, display, mouse/keyboard input, music/sound, and save/load results.
- Problems, workarounds, and whether results were reproduced.

Use “not tested” for unchecked features. Avoid publishing absolute personal paths,
proprietary logs/data, or unsupported claims that a configuration is optimal.
